- C64-07 to C64-08: Data standards (ISO 4217, RFC 3339), mandatory API headers
- C64-09 to C64-10: E-wallet (EWLTS) and Payment Initiation (PIS) API endpoints
- C64-11 to C64-12: Consent management, audit logging
- C64-13 to C64-16: Error responses, security level, third-party access, testing system
